# Setup

Здесь в следующих спринтах будут размещены воспроизводимые инструкции и сценарии подготовки Ubuntu ARM64, `swtpm`, `tpm2-tools` и `tpm2-tss`.

В Sprint 01 установка и настройка TPM-стека не выполняются.

Ранний ARM64 Docker technical spike Sprint 02 находится в `infra/docker-tpm/` и описан в `docs/labs/docker-arm64-swtpm-runbook.md`. Это не замена целевой UTM/QEMU VM.
